# 英作文トレーニングアプリ

Streamlitを使用した英作文トレーニングアプリケーションです。段階的な学習と穴埋めテストで英語力を向上させます。

## セットアップ

### 1. 仮想環境の作成とアクティベート

```bash
# 仮想環境を作成
python -m venv venv

# 仮想環境をアクティベート
source venv/bin/activate  # macOS/Linux
# または
venv\Scripts\activate     # Windows
```

### 2. 依存関係のインストール

```bash
pip install -r requirements.txt
```

### 3. アプリケーションの実行

```bash
streamlit run app.py
```

## 学習モード

### 📚 段階的学習モード
英文を覚えるための段階的な学習を行います：

1. **ステップ1: 英文確認** - 英文を表示し、音声で読み上げ
2. **ステップ2: 日本語訳確認** - 日本語訳を表示し、音声で読み上げ
3. **ステップ3: タイピング練習** - 英文を入力して覚える
4. **ステップ4: 穴埋めテスト** - 重要な単語を穴埋めで確認

### 🎯 穴埋めテストモード
直接穴埋めテストを行います：

- 日本語訳を表示
- 穴埋め英文を表示
- 空欄に適切な英単語を入力
- ヒント機能と正解表示機能

### 🎲 ランダム学習モード
未完了のレッスンからランダムに選択して学習します：

- ランダムにレッスンを選択
- 簡潔な学習フロー
- 次のランダムレッスンへの移動

## 機能

- **音声読み上げ**: 英語・日本語の音声読み上げ機能
- **進捗管理**: 完了したレッスンの記録と進捗表示
- **ランダム選択**: 未完了レッスンからのランダム選択
- **タイピング練習**: 英文を入力して覚える練習
- **穴埋めテスト**: 重要な単語の穴埋めテスト

## 使用方法

1. アプリケーションを起動すると、ブラウザで自動的に開きます
2. サイドバーで学習モードを選択します
3. 段階的学習モードでは、4つのステップを順番に進めます
4. 穴埋めテストモードでは、直接テストを行います
5. ランダム学習モードでは、ランダムにレッスンが選択されます
6. 進捗は自動的に記録され、サイドバーで確認できます

## ファイル構成

- `app.py` - メインアプリケーションファイル
- `data.yaml` - 教材データ（YAML形式）
- `requirements.txt` - 依存関係リスト
- `README.md` - このファイル

## データの管理

教材データは `data.yaml` ファイルで管理されています。新しい例文を追加する場合は、以下の形式で `data.yaml` に追加してください：

```yaml
lessons:
  - ja: "日本語の例文"
    en: "English example sentence"
    gaps: ["example", "sentence"]
```

## 仮想環境の終了

```bash
deactivate
```
